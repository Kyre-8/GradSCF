# Before the frequency-cluster precision correction

These are the prior FFT61 outputs with 2596/2604 certified selected roots.
Gamma bands 6 and 7 were rejected by using root stopping tolerances to
define frequency degeneracy. This Git snapshot retains the prior figures,
metadata and QA. Its duplicate `comparison.npz` and full scGW source-state
files are retained separately under the [source-checkout packaging
policy](../../../PACKAGING.md). The original postprocessing manifest records
the eight input hashes shared with the updated calculation; it describes
the original execution bundle, rather than checkout completeness. No
executable code is stored in this snapshot.
